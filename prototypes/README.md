# 王舒悦 · 个人网站 / 三个方向

同一组内容样本：12 篇文章，政论、艺术、技术、哲学各 3 篇；文章页共用一篇完整样稿《在展厅里走神》。<br>
三套都能点开、能筛选、能读文章；区别只在设计本身。

> 篇目、简介、正文均为占位内容；邮件与 RSS 是占位链接；所有文章条目暂时指向同一篇样稿，用来看文章页版式。

## A · 文稿

暖纸色、宋体、细线，左侧一条很窄的日期栏，按年份往下排。文章页把日期和类别放在左栏，注释放到右侧页边，正文保持单栏。

- 适合：以长文阅读为主，希望网站像一本已经排过版的文集。
- 代价：首页比较长，视觉记忆点不如 B、C 强。
- 首页：[a-manuscript/index.html](a-manuscript/index.html)
- 文章页：[a-manuscript/essay.html](a-manuscript/essay.html)

## B · 索引

冷白底、无衬线标题、完整网格。每篇有稳定的 No. 编号，类别只用一个 5px 色点。筛选带计数；文章页左侧变成一张作品资料卡。

- 适合：文章会持续增加，希望有资料库、目录、档案的感觉。
- 代价：更像一套系统，个人气息较弱；卡片留白较多。
- 首页：[b-index/index.html](b-index/index.html)
- 文章页：[b-index/essay.html](b-index/essay.html)

## C · 书脊

纯白底、左侧竖排书脊、很大的留白。首页只放 8 篇近作，全部文章单独一页；文章页把一句关键句提成引文。

- 适合：希望首页像一次策展，作者气质更强。
- 代价：三套里设计痕迹最明显，需要接受大面积空白，也需要“精选 + 归档”两层结构。
- 首页：[c-spine/index.html](c-spine/index.html)
- 全部文章：[c-spine/archive.html](c-spine/archive.html)
- 文章页：[c-spine/essay.html](c-spine/essay.html)

## 横向比较

| | A 文稿 | B 索引 | C 书脊 |
|---|---|---|---|
| 第一眼 | 安静、偏文学 | 清楚、偏档案 | 空、偏展览 |
| 长文阅读 | 最好 | 好 | 好 |
| 文章变多以后 | 可以，但页面会变长 | 最从容 | 需要归档页 |
| 个人气质 | 中 | 弱 | 强 |
| 设计风险 | 低 | 低 | 中（留白与竖排是明确姿态） |

如果按“简洁、不做作、不留痕迹”来排，我自己的顺序是 **A → B → C**。A 最把注意力留给文字；C 最漂亮，但竖排书脊是一个明确的签名，喜欢它再选。
