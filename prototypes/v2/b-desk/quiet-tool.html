The Quiet Tool

We notice a tool when it breaks. A chair wobbles, a key sticks, a model returns something slightly wrong. Until that moment the tool has been part of the room, as unremarkable as the floor.

This is what good tools do: they recede. A hammer does not ask to be interpreted. A calendar does not explain its ontology.

The best interface lets the task take up the whole of your attention, and then forgets itself.

Consider a pencil. It has no settings, no updates, no view about how you should hold it. Its silence is a kind of freedom. But the silence of a system that watches, sorts, and suggests is a different silence altogether—one that has opinions it does not have to declare.

Recession is not innocence. A tool can disappear while still making decisions: the default sort order, the route we are given, the word the keyboard suggests before we have finished thinking. The Chinese word for tool, 工具, carries no promise of neutrality; it simply names what is at hand.1 A knife is useful precisely because it is sharp, and dangerous for the same reason.

We need a criticism that can see both. Not a suspicion of tools in general, which quickly becomes a suspicion of everything, but attention to the moment when a tool stops being a background and starts being an author. The question is not whether the tool is neutral. It never was. The question is who is speaking when it seems to be silent.

The quietest tools are the ones we should learn to hear.

1I use tool in the broad sense: an object, interface, or procedure that extends an intention. 工具 is narrower, closer to “instrument” or “implement”; 器物 keeps the weight of the object itself.
